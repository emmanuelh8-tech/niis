Licensed fonts for NIIS. Put the licensed web font files here with these names and they are used
at once (views.js checks this folder when the server starts):

  marvin-visions.woff2  (or .woff / .otf / .ttf)  - Marvin Visions, for category labels
  kazimir.woff2         (or .woff / .otf / .ttf)  - Kazimir, for bylines and dates

Until they are here, the free stand-ins Righteous and Spectral (Google Fonts) are shown.

For the About page's slides (drawn into images by design/about-slides; render them again after adding):

  delphin.woff2           (or .woff / .otf / .ttf)  - Delphin, for the slides' headings
  sully-jonquieres.woff2  (or .woff / .otf / .ttf)  - Sully-Jonquieres, for the slides' text

Until they are here, the slides use the free stand-ins Fondamento and Marcellus.
